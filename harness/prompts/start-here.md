## The prompt

By the end of this conversation I want a written recommendation: which AI tools to use for the work I'm about to do, how to set each one up, and why. Name specific products. Include tools that aren't AI if they'd help.

To get there, interview me about my situation, one question at a time. I haven't planned the work yet, so don't ask me to. What you need to know:

- What I'm about to do, in a sentence, and whether it's a one-off task or something I'll keep working on.
- What tools I already have, at work and at home, and what I'm allowed to use.
- What I already work in day to day, so the AI can meet me there.
- How comfortable I am with technology, and whether I want to learn a new tool or just get this done.
- Anything that rules tools out: budget, privacy, time.

The tool landscape changes fast, so search the web for current options before you recommend. Tell me about options I may not know exist, including tools that work inside the apps I already use and tools that can act for me, not just chat.

As soon as you have enough, recommend a setup. If more than one approach is worth considering lay out two or three, each with its tools, setup, and reason, and say which you'd pick. Ask what I'd push back on. When I say it's right, write it as a setup note I can keep. Then stop.
