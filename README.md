# Start Here: HORSE

An end-to-end framework for how to use any AI tool effectively.


H - Harness: The environment you give the AI: the tool you use, and the files, context, and permissions it has. The models underneath are much alike, so the harness is what decides what the AI can see and do.

O - Objective: The outcome you want to have happen. A task is something you ask the AI to do, and the objective is what that task is for.

R - Role: How you want the AI to work with you. It covers both the division of labor, from doing the work for you to teaching you to do it yourself, and the way the AI should act along the way.

S - Scope: The boundaries of the work. What's in, what's out, what good looks like, and what done looks like.

E - Evaluate: Judging whether the output is good by checking it against your objective and scope. It means being able to tell quality from slop, and going back and forth until the work is right.
